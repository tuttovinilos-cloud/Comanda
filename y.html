RESUMEN FUNCIONAL · ANALIZADOR / COTIZADOR + MATERIA PRIMA TUTTOVINILOS 1. IDEA GENERAL El sistema debe separar claramente tres cosas: 1) El Analizador SVG - Solo calcula los parámetros base del diseño. 2) Materia Prima / Item.html - Es la tabla madre de materiales, precios, proveedores y tipo de cálculo. 3) Materiales Compuestos - Son fórmulas que usan los parámetros base del SVG y los materiales reales de Item.html para calcular costo, precio de venta y ganancia. 2. PARÁMETROS BASE DEL SVG El analizador/cotizador debe calcular: - Perímetro - Cantidad de piezas - Área de relleno - Área de marco - Área de selección - Ancho real - Alto real - Escala usada Los códigos K43, K44, K45 y K46 pueden omitirse visualmente. Deben mostrarse con nombres claros para el usuario. 3. LÓGICA DEL PRECIO El precio no debe salir directamente del SVG. El SVG solamente genera los parámetros base. El precio calculado debe salir del material compuesto seleccionado. Ejemplo: Si se selecciona Front Lit: - PVC 9mm puede usar área de marco. - Acrílico puede usar área de marco. - Módulos LED pueden usar área de relleno. - Cable puede usar perímetro o fórmula especial. - Chupones pueden usar cantidad de piezas. - Pernos pueden usar cantidad fija o por pieza. El compuesto decide cómo usar los parámetros base. 4. MATERIALES BASE DESDE ITEM.HTML La pestaña Materiales / Compuestos del analizador no debe tener una lista independiente de materiales. Debe estar anclada a la misma lista de Item.html / Materia Prima. Eso significa que debe leer desde Supabase: - materia_materiales - materia_precios - proveedores - categoría - nombre - detalle - tipo de medida - formato - área m² - metros lineales - precio - proveedor más barato No deben existir materiales duplicados en localStorage dentro del analizador. 5. TIPOS DE CÁLCULO DE MATERIALES Item.html ya maneja diferentes formas de precio: 1) M² Para materiales como: - PVC - Acrílico - ACM - MDF - Láminas 2) Metro lineal Para materiales como: - Vinil en rollo - Cable - Cinta - Banda 3) Unitario Para materiales como: - Módulos LED - Pernos - Chupones - Pegas - Estaño - Interruptores El material compuesto debe respetar el tipo de cálculo del material base. 6. PESTAÑA ANALIZADOR / COTIZADOR Debe mostrar: - Carga de SVG - Medida real - Vista previa - Parámetros base - Selección de material compuesto - Resultado del cálculo Debe mostrar: - Costo real - Precio de venta - Ganancia - Desglose opcional 7. PESTAÑA MATERIALES / COMPUESTOS Debe tener dos bloques principales: A) Materiales base Debe mostrar la misma lista de materiales de Item.html: - Categoría - Nombre - Detalle - Tipo de medida - Formato - Mejor proveedor - Precio base - Precio por m², metro o unidad Esta lista debe ser solo para consultar y seleccionar materiales. B) Materiales compuestos Aquí se crean las fórmulas de productos como: - Front Lit - PVC + Acrílico - Letras con luz - Letras sin luz - Neón LED - Base con luz - Producto personalizado 8. CAMPOS DEL MATERIAL COMPUESTO Cada grupo compuesto debe tener: - Nombre del grupo - Componente - Unidad - Base - Factor de consumo - Extra - Redondear - Factor de venta - Costo real - Precio venta - Ganancia Bases disponibles: - Perímetro - Cantidad de piezas - Área de relleno - Área de marco - Área de selección - Fijo/manual - Fórmula especial 9. DIFERENCIA ENTRE FACTOR DE CONSUMO Y FACTOR DE VENTA No deben mezclarse. A) Factor de consumo Sirve para calcular la cantidad de material. Ejemplos: - Módulos LED = área de relleno × 220 - Chupones = cantidad de piezas × 4 - Cable = perímetro × 1.2 - PVC = área de marco × 1 B) Factor de venta Sirve para calcular la ganancia. Ejemplos: - PVC costo $100 × factor venta 2 = $200 - Módulo LED costo $0.75 × factor venta 5 = $3.75 - Cable costo $1 × factor venta 3 = $3 10. FÓRMULAS DE COSTO, PRECIO Y GANANCIA Por cada componente: Cantidad calculada = Base × factor de consumo + extra Costo real = Cantidad calculada × precio base del material Precio venta = Costo real × factor de venta Ganancia = Precio venta - costo real Fórmula resumida: Precio venta = precio material × factor venta Ganancia = precio venta - precio material 11. EJEMPLO SIMPLE Material: PVC Costo real: $100 Factor venta: 2 Precio venta: $200 Ganancia: $100 12. EJEMPLO FRONT LIT Parámetros SVG: - Área de marco: 1.20 m² - Área de relleno: 0.85 m² - Perímetro: 6.50 m - Piezas: 8 Componentes: 1) PVC 9mm Base: área de marco Consumo: 1.20 m² Factor consumo: 1 Factor venta: 2 2) Acrílico 3mm Base: área de marco Consumo: 1.20 m² Factor consumo: 1 Factor venta: 2 3) Módulos LED Base: área de relleno Consumo: área × 220 Factor venta: 5 4) Cable Base: perímetro Consumo: perímetro × 1.2 + extra Factor venta: 3 5) Chupones Base: piezas Consumo: piezas × 4 Factor venta: 2 13. VISUALIZACIÓN MIENTRAS SE CREA EL COMPUESTO Cuando se esté armando un grupo compuesto, al seleccionar un material debe mostrar: - Precio base actual - Tipo de cálculo - Proveedor más barato - Cantidad estimada - Costo real estimado - Factor de venta - Precio venta estimado - Ganancia estimada - Total acumulado del compuesto Esto permite trabajar viendo si el precio tiene sentido. 14. GUARDAR MATERIAL COMPUESTO Al guardar un compuesto: 1) Guardar en base de datos. 2) Mostrar aviso: Grupo guardado. 3) Limpiar el formulario. 4) Dejar una línea nueva lista. 5) Actualizar la lista de compuestos. Después debe permitir: - Editar - Duplicar - Eliminar 15. BASE DE DATOS RECOMENDADA PARA COMPUESTOS Se recomienda crear tablas separadas: A) materia_compuestos Campos sugeridos: - id - nombre - descripcion - activo - created_at - updated_at B) materia_compuesto_componentes Campos sugeridos: - id - compuesto_id - material_id - base_parametro - factor_consumo - extra - redondear - factor_venta - orden - activo - created_at - updated_at Así los compuestos quedan guardados en Supabase y no en localStorage. 16. FLUJO FINAL DEL SISTEMA 1) El usuario registra materiales y precios en Item.html. 2) El analizador SVG lee esos materiales. 3) El usuario crea materiales compuestos usando esos materiales. 4) El usuario sube un SVG. 5) El sistema calcula parámetros base. 6) El usuario selecciona un compuesto. 7) El sistema calcula: - Costo real - Precio de venta - Ganancia - Desglose 8) Se puede exportar resumen o PDF. 17. CONCLUSIÓN La estructura correcta es: Item.html = tabla madre de materiales y precios. Analizador SVG = cálculo técnico del diseño. Material compuesto = fórmula comercial que convierte el análisis en costo, precio y ganancia. Esto evita duplicar materiales, mejora el control de precios y permite crear productos complejos como Front Lit usando datos reales.
